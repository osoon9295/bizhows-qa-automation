# 장바구니 주문 금액 테스트

## 테스트 목적

장바구니 상품 선택 상태에 따른 주문 금액을 검증한다.

검증 대상은 다음과 같다.

- 주문 금액
- 상품 할인 금액
- 배송비
- 총 금액
- 선택 상품이 없을 때 주문하기 버튼 비활성화 여부

## 사전 조건

- BizHows 로그인 상태가 필요하다.
- `playwright/.auth/user.json` 인증 상태 파일이 필요하다.
- 테스트 실행 전에 장바구니에 상품을 정확히 2개 추가해야 한다.
- 두 상품 모두 원가와 할인가가 화면에 표시되어야 한다.

## 테스트 로그인 및 인증 상태 설정

장바구니 테스트는 매번 로그인 UI를 자동화하지 않고, Playwright의
`storageState`를 사용해 저장된 로그인 상태를 재사용한다.

### 최초 로그인

1. 아래 명령을 실행한다.

   ```bash
   npx playwright codegen \
     --save-storage=playwright/.auth/user.json \
     https://www.bizhows.com/ko
   ```

2. Playwright 브라우저에서 BizHows에 로그인한다.
3. 장바구니에 상품 2개를 수동으로 추가한다.
4. 로그인과 장바구니 상태가 저장된 브라우저를 종료한다.
5. `playwright/.auth/user.json` 파일이 생성되었는지 확인한다.

### 인증 상태 확인

```bash
npx playwright test tests/auth/auth-check.spec.ts
```

인증 상태 확인 테스트가 성공하면 저장된 로그인 상태로 장바구니 페이지에
접근할 수 있다.

### 인증 상태 갱신

다음 상황에서는 인증 상태를 다시 저장한다.

- `user.json` 파일이 없는 경우
- 로그인 세션이 만료된 경우
- 인증 상태 확인 테스트가 실패하는 경우
- 계정이나 로그인 방식이 변경된 경우

`playwright/.auth/user.json`에는 세션 정보가 포함될 수 있으므로 Git에
커밋하지 않는다.

## 검증 시나리오

### 상품 0개 선택

- 주문 금액이 `0원`인지 확인한다.
- 상품 할인 금액이 `- 0원`인지 확인한다.
- 배송비가 `0원`인지 확인한다.
- 총 금액이 `0원`인지 확인한다.
- 주문하기 버튼이 비활성화되어 있는지 확인한다.

### 상품 1개 선택

- 선택한 상품의 원가를 기준으로 주문 금액을 확인한다.
- 상품 할인 금액을 확인한다.
- 배송비를 포함한 총 금액을 확인한다.

### 상품 2개 선택

- 두 상품의 주문 금액 합계를 확인한다.
- 두 상품의 할인 금액 합계를 확인한다.
- 배송비를 포함한 총 금액을 확인한다.

## 실행 방법

장바구니 주문 금액 테스트를 실행한다.

```bash
npx playwright test tests/cart/cart-amount.spec.ts
```

Chromium에서만 실행하려면 다음 명령을 사용한다.

```bash
npx playwright test tests/cart/cart-amount.spec.ts --project=chromium
```

HTML 리포트를 확인하려면 다음 명령을 사용한다.

```bash
npx playwright show-report
```

## 실패 시 확인 사항

- 로그인 세션이 만료되지 않았는지 확인한다.
- `playwright/.auth/user.json` 파일이 존재하는지 확인한다.
- 장바구니에 상품이 정확히 2개 있는지 확인한다.
- 두 상품의 원가와 할인가가 표시되는지 확인한다.
- 장바구니 페이지에 정상적으로 접근되는지 확인한다.
- 팝업이 화면을 가리고 있지 않은지 확인한다.
- 상품 가격 또는 배송비 정책이 변경되지 않았는지 확인한다.
